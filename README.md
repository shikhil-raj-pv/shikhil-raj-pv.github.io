## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (v16 or higher) and `npm` installed.

### Installation & Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/shikhil-raj-pv/shikhil-raj-pv.github.io.git
   cd shikhil-raj-pv.github.io
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Static Export & Deployment

### Local Build

To build and generate static HTML/JS/CSS output in the `out/` directory:

```bash
npm run build
```

### GitHub Pages Deployment

The site deploys automatically to **GitHub Pages** using GitHub Actions whenever changes are pushed to the `main` branch.

1. Push changes to `main`:
   ```bash
   git add .
   git commit -m "Update portfolio"
   git push origin main
   ```
2. Enable GitHub Actions deployment: **GitHub Repo Settings → Pages → Source → GitHub Actions**.
